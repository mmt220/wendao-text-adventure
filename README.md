# 问道长生 · WENDAO

一段纯文字的仙侠文字冒险。没有战斗动画、没有立绘——纸、墨、文字，和你的选择。

> 长生不是不死，是不忘。

## 怎么玩

直接用浏览器打开 `index.html` 即可（无任何构建步骤、无后端、无依赖）。

- **做出选择**：每个抉择都会改变你的修为、心境与寿元，并积累看不见的因果
- **六种结局**：飞升、散仙、兵解转世、吞天真魔、寿元坐化、心魔反噬
- **三条出身路线**：宗门弟子 / 江湖散修 / 西荒鬼市，各自有不同的劫难与机缘
- **多周目**：灵根随机开局、秘境概率事件、善恶因果，每一世都不同
- **前尘面板**：随时回看此生走过的每一步
- **昼夜切换**：纸墨昼色 / 夜修墨色，自动记忆偏好
- **自动存档**：进度存在浏览器 localStorage，关掉页面下次续上

键盘党可以按 `1`~`9` 直接选择选项。

## 系统

| 数值 | 含义 |
| ---- | ---- |
| 修为 | 决定境界与渡劫时的底气（筑基 → 金丹 → 元婴 → 化神 → 渡劫） |
| 心境 | 心魔的闸门。归零之日，便是心魔替你做主之时 |
| 寿元 | 时间是修仙路上最锋利的刀。耗尽即坐化 |
| 因果 | 善恶皆有回响，影响结丹品相与最终结局 |

## 技术

- 纯手写 HTML / CSS / 原生 JavaScript，零依赖、零构建
- Canvas 手绘水墨环境：三层正弦远山、流动雾气、飘落墨瓣（60fps，支持高分屏）
- 剧情数据与引擎分离（`js/story.js` / `js/engine.js`），想续写剧情只需加节点
- 思源宋体 + 站酷小薇 + 楷体回退字体栈

## 本地运行

```bash
# 任选其一
open index.html
python3 -m http.server 8000   # 然后访问 http://localhost:8000
```
