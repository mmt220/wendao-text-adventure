# 问道长生 · WENDAO

一段纯文字的仙侠文字冒险。没有战斗动画、没有立绘——纸、墨、文字，和你的选择。

> 长生不是不死，是不忘。

## 怎么玩

直接用浏览器打开 `index.html` 即可（无任何构建步骤、无后端、无依赖）。

## 系统一览

### 核心数值
| 数值 | 含义 |
| ---- | ---- |
| 修为 | 决定境界与渡劫底气（炼气 → 筑基 → 金丹 → 元婴 → 化神 → 渡劫） |
| 心境 | 心魔的闸门。归零之日，心魔替你做主 |
| 寿元 | 时间是修仙路上最锋利的刀，耗尽即坐化 |
| 因果 | 善恶皆有回响，影响结丹品相与最终结局 |

### 天命随机
- **灵根随机判定**：天灵根 / 雷灵根 / 五行杂灵根，开局即定，不可更改
- **突破有成败**：筑基、冲金丹都有真实失败率（心境、修为、灵根影响胜算），失败走火入魔、修为大损——赌，还是不赌？
- **奇遇系统**：14 个随机奇遇（老丐、灵雨、邪修拦路、坊市捡漏、心魔低语……），在历练途中随时触发，高风险高收益

### 好感度系统（善缘）
五位 NPC，好感分五级：陌路 → 相识 → 熟识 → 挚友 → 生死之交（负值则结仇）。

- **独臂翁**：黑风峡的独臂老散修，挚友的调停能化解血仇
- **云姝**：青云宗内门师姐，好感足够可在月下结为道侣
- **青翎**：秘境中救下的碧鳞小蛇，养到生死之交，渡劫时它会替你挡雷
- **鬼市老妪**：鬼市的引荐人，得罪了她，西荒再无你容身之处
- **道侣**：红尘中人，情之一字可改天命

### 轮回图鉴
- **七种结局**：飞升 / 散仙 / 同渡 / 兵解 / 入魔 / 坐化 / 心魔
- **轮回印记**：每达成一种结局留下一道印记，下一世开局修为 +3、心境 +2（印记永久保留）
- 命簿面板随时查看：前尘（选择记录）· 善缘（好感度）· 图鉴（结局收集）

### 其他
- 三条出身路线：宗门 / 散修 / 鬼市，各自的劫难、机缘与旧账
- 昼夜切换（纸墨昼色 / 夜修墨色），自动记忆偏好
- 自动存档（localStorage），关掉页面下次续上
- 键盘 1~9 快选，`Esc` 关闭命簿

## 技术

- 纯手写 HTML / CSS / 原生 JavaScript，零依赖、零构建
- Canvas 手绘水墨环境：三层正弦远山、流动雾气、飘落墨瓣（60fps，支持高分屏）
- 剧情 / 事件 / 引擎三层分离（`story.js` / `events.js` / `engine.js`），续写剧情只需加节点
- 思源宋体 + 站酷小薇 + 楷体回退字体栈

## 本地运行

```bash
open index.html
# 或
python3 -m http.server 8000   # http://localhost:8000
```
